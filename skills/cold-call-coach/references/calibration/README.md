# Grading Calibration Examples

These three anonymized reports are graded reference calls: a truncated full call scored Strong (example_full_strong.md), a complete full call scored Needs Work (example_full_needswork.md), and a true short call with a conversion attempt (example_short_call.md). All names, addresses, phone numbers, and links are fake or redacted; every score, rationale, and JSON footer is real output from a calibrated grading pass.

Read all three BEFORE your first grading session in any run. They define what each score anchor looks like in practice: when to mark N/A vs 0, when to redistribute category weights, when a call routes short vs full, and what counts as a conversion attempt. Stay consistent with these examples; if your instinct on a live call disagrees with how an identical situation was scored here, follow the example. Each file opens with a "Why this call grades this way" preamble naming the judgment calls new graders most often get wrong.
